## Этап 1: Разведочный анализ (EDA) и подготовка данных

**Что за данные:** Исторические логи почасового трафика (кол-во машин) на 4 городских перекрестках. Охват — около 1.5 лет (с ноября 2015 по июнь 2017). Целевая переменная — `Vehicles`.

### Ключевые выводы из анализа:
1. **Фильтрация мусора:** Перекрестки 1, 2 и 3 имеют полные непрерывные ряды (ровно по 14 592 точки). Перекресток №4 оказался урезанным (данных меньше в 3.5 раза), поэтому мы его полностью выкинули из датасета, чтобы он не ломал логику глобальных моделей.
2. **Проверка сетки:** Скрытых временных дыр и пропусков в часах нет — ряд непрерывный, шаг строго 1 час.
3. **Стационарность:** Тест Дики-Фуллера (ADF) выдал нулевой p-value для всех рабочих перекрестков. Ряды стационарны, так что возиться со взятием разностей не придется.
4. **Сезонность:** Обнаружена жесткая двойная сезонность:
   * *Суточная:* Два четких пика в день (утренний час пик 7:00–9:00 и вечерний 17:00–19:00).
   * *Недельная:* В выходные дни (суббота и воскресенье) трафик предсказуемо и сильно падает по сравнению с буднями.
5. **Аномалии:** Выбросы причесали методом IQR-клиппинга (винсоризации) строго изолированно внутри каждого перекрестка. Экстремальные пики зажали по границам, при этом сама временная сетка осталась целой.

**Итог этапа:** Данные очищены, приведены к стандартному формату библиотек Nixtla (`unique_id`, `ds`, `y`) и сохранены в файл `data/traffic_clean.csv`. Все готово к быстрому моделированию.
