**Данные**: 48 120 строк, 01.11.2015 – 30.06.2017. Пропусков нет. `DateTime` → индекс, `ID` удалён.

**Перекрёстки**: 1,2,3 — полные; 4 — фрагментирован (исключён).

**Пропуски по времени** (Junction 1): отсутствующих часов нет.

**График всех перекрёстков** показывает чёткие суточные циклы.  
**Boxplot по часам** (Junction 1):
- Максимальный поток в **12:00** и **19:00**.
- В часы пик разброс значений шире (за счёт верхних выбросов), нижняя граница потока достаточно стабильна.

**Стационарность**: ADF-тест p ≈ 0 (ряд стационарен). Сезонность ярко выражена, будут использоваться сезонные модели.

**Тренд**: на графике ежедневных сумм виден восходящий тренд (рост трафика к 2017).

**Аномалии** (IQR): 2823 выброса (≈6,4%). Удалять все не буду — часть из них реальные всплески.

**Чистые данные** (перекрёстки 1–3) сохранены в `traffic_clean.csv`.
